# Roblox Studio workspace

This folder is reserved for source that is intentionally managed as text (for example Luau scripts, configuration, and asset manifests). The live `.rbxl` place is not included in this starter package. Do not assume GitHub files automatically synchronize with Studio. Before adopting Rojo or migrating instances out of the place file, inspect the current project and plan a separate migration.


Before importing the texture UI modules, follow [STUDIO_IMPORT_GUIDE.md](STUDIO_IMPORT_GUIDE.md) for the expected Explorer hierarchy, asset-ID caveats, and smoke-test steps.

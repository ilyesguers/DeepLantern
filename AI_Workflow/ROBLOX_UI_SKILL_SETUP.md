# Roblox UI Skill Setup

Reference skill repository: https://github.com/afrxo/roblox-agent-skills
Relevant skill: `skills/roblox-ui/SKILL.md`.

Use the skill as implementation guidance for Roblox UI conventions; it is not itself a Studio editor or a guarantee of access. Review the repository's current installation instructions for the agent you use.

For each UI task:
- Follow approved art direction and existing project hierarchy.
- Keep mobile, landscape/portrait, and low-end performance in mind.
- Use existing approved asset IDs; never invent replacements.
- Preserve live resource values and actual gameplay state.
- Do not add radar/depth widgets or mechanics unless the GDD authorizes them.
- Provide a plan and wait for approval before editing.
- Test at representative desktop and mobile resolutions and report what was actually tested.

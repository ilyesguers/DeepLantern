# Change Checklist

Before:
- [ ] Read AI_START_HERE, PROJECT_STATE, approved GDD and implementation notes.
- [ ] Confirm correct working copy and backup.
- [ ] Inspect exact script/instance paths and current behavior.
- [ ] State scope, expected result, risks, and test/rollback plan.
- [ ] Wait for user approval.

After:
- [ ] Summarize exact files/instances changed.
- [ ] Run and report actual tests; clearly mark tests not run.
- [ ] Check client/server ownership and mobile UI behavior where relevant.
- [ ] Confirm no unrelated behavior was changed.
- [ ] Record remaining issues and rollback steps.
- [ ] Update CHANGELOG and agent handoff.
- [ ] Do not save/publish without explicit approval.

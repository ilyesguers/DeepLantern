# File Map

- `AI_START_HERE.md`: mandatory onboarding.
- `PROJECT_STATE.md`: current verified state and known limitations.
- `GDD/`: approved design specification.
- `Docs/IMPLEMENTATION_NOTES.md`: implementation clarifications.
- `Art/VisualReference/`: visual references only.
- `Assets/Textures/`: production textures only, with licensing and usage notes.
- `Assets/Models/`: exported production models only, with scale/pivot/collision notes.
- `Blender/`: Blender asset pipeline and source files.
- `Roblox/`: Studio integration notes.
- `AI_Workflow/`: agent rules, setup, task templates, test and handoff processes.
- `CHANGELOG.md`: user-approved project changes.

Do not infer that a folder contains production assets simply because it contains reference art. Inspect the actual project before mapping Studio instances.

# Textures

The production texture pack imported from the supplied archive is under `Assets/Textures/TEXTURES/`; its `manifest.json` documents palette, maps and intended use. Read `Assets/Textures/TEXTURES/README.md` and `README.ar.md` before importing assets.

Keep concept/reference boards under `Art/VisualReference/`; never apply a whole board as a texture to a part. For each new/modified texture, record dimensions, color space, target object/material, tiling/UV assumptions, transparency, compression/import settings and source/license. For Roblox materials, follow the manifest's map conventions and verify import/appearance in Studio before marking an asset production-ready.

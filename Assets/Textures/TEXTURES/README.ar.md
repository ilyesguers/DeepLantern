# حزمة Textures للعبة Deep Lantern (بالعربية)

هذه الحزمة جاهزة لتستخدمها أنت أو أي ذكاء اصطناعي مباشرة داخل Roblox Studio. ابدأ بفتح مجلد `previews/` لترى كل شيء في خمس صور.

## ما بداخلها
- **39 مادة** متكررة (PBR): صخور وحصى ومبانٍ قديمة وجروف وأسطح غواصات بستة ألوان وبلورات وقشور وجلود مخلوقات وأحجار آثار.
- **49 عنصر واجهة**: ألواح زجاجية بحواف مشطوفة، وأزرار بخمس حالات، وأشرطة Battery/Hull/Cargo.
- **111 أيقونة** (بإضاءة وظل وعمق) بنسختين: ملونة وبيضاء قابلة للتلوين، ومجمّعة في 4 atlases.
- **29 تأثيرًا بصريًا**: فقاعات، ثلج بحري، أشعة الفانوس، سونار، ماسح، تنبيهات حافة الشاشة.
- **هوية بصرية**: الشعار، وأيقونة اللعبة (512)، وخلفية التحميل، ولافتات المحطة.
- **كود Luau**: رموز التصميم ومحمّل الـ textures، ومكوّنات Fusion جاهزة (لوحة، زر، شريط مورد، شريط بدن، إشعارات، وشاشة الغوص الكاملة).
- **أدوات**: مولّدات Python لإعادة التوليد، وفاليديتر آلي، وسكربت رفع إلى Roblox.

## خطوات الاستخدام
1. شغّل `python3 _generators/validate.py` وتأكد أن النتيجة 0 errors.
2. ارفع الصور إلى Roblox: يدويًا عبر Asset Manager، أو بسكربت `upload_assets.py` (جرّب `--dry-run` أولًا). ثم ضع الأرقام في `luau/AssetIds.luau`.
3. ضع مجلد `luau` داخل `ReplicatedStorage` باسم `DeepLantern`، وثبّت Fusion 0.3 في `ReplicatedStorage.Packages`.
4. جرّب `DiveHUD.demo.client.luau` لترى شاشة الغوص.

## قواعد مهمة (من وثيقة التصميم)
- لا خريطة مصغّرة، ولا مؤشرات GPS، ولا انتقال سريع، ولا عملة ثالثة، ولا صناديق حظ.
- لا تعتمد على اللون وحده: دائمًا أيقونة مع نص.
- الإشعارات تختفي بعد ~3 ثوانٍ، وعناصر الواجهة الثانوية تخفت بعد ~5 ثوانٍ من الإبحار الهادئ.

## تحفّظات صريحة
- التصاميم مولّدة بالكود: قاعدة متسقة وممتازة للبداية، لكنها ليست رسمًا يدويًا. الشخصيات والـ key art تحتاج فنانًا أو نموذج صور.
- كود Luau لم يُجرَّب داخل Studio، وسكربت الرفع لم يُجرَّب على الـ API الفعلي.
- عتبات تحذير البطارية (30% و15%) مؤقتة، فالوثيقة تؤجّل الأرقام الدقيقة إلى مرحلة الموازنة.

# Models

No production-ready Blender models are included in this archive import. Keep reference boards in `Art/VisualReference/`, not here.

For each approved model, create `Assets/Models/<AssetName>/` containing:
- editable `.blend` source;
- exported `.fbx` or another agreed import format;
- `preview.png`;
- `README.md` documenting intended use, scale (studs/meters), origin/pivot, triangle estimate, materials and texture references, collision plan, export settings, and source/license.

Start with one low-risk prop after the pipeline is verified. Do not create a full station or submarine model before the user approves the visual target and scope. Verify the asset in a separate Roblox Studio working copy before calling it production-ready.

# Abyssal Shark Boss — user-supplied FBX sample

Status: UPLOADED_TO_GITHUB (sample/reference only, NOT part of the DL-001..DL-020 queue).

This is a real 3D model exported from Blender 5.2.2 by the repository owner and supplied to a Claude session on 2026-10-22. It was not generated by Claude.

## GDD scope warning
Do not place this in the game as-is. The approved GDD has no boss, combat or "Abyssal" shark entry, and the Abyss is a post-MVP zone. Use it as a style/pipeline reference or for a later GDD revision only.

## Contents
- `model.fbx` — binary FBX 7.4, 98 named mesh parts (prefix `SHARK |`), 9 flat-color materials, no image textures.
- `manifest.json` — figures measured by parsing the file (vertices 13,684; triangles 26,884; raw bounds), plus a list of things that were NOT verified.

## Not verified (do not assume)
Real scale/units, axis orientation, pivot, UVs, normals, Roblox Studio import, and licensing beyond owner-supplied. No preview image exists.

## Notes for the next session
- Roughly 27k triangles in 98 parts is heavy for mobile; merge parts per material and reduce before any use.
- The same owner also supplied a blocky Blender script (`boss_shark_blender.py`, one mesh per color, 1 unit = 1 stud, FBX export). It was not committed; ask the owner if you need it.
- The FBX embeds the owner's original local `.blend` path in its metadata.

# DL-004 — Sample Canister Family

**Priority:** P0  
**Status:** QUEUED

## Goal
Create a reusable family of three specimen containers that make discoveries feel valuable and scientifically meaningful. The family must share a common design language but each variant should be visually distinct.

## Variants
- **Standard sample capsule:** compact cylindrical pressure container, transparent protected central chamber, two reinforced end caps, locking clamps and carry handle.
- **Fragile biological sample:** rounded transparent chamber inside a protective cage, soft cyan/purple contents placeholder represented as geometry/material, shock-isolating mounts.
- **Rare mineral/specimen vault:** squat hexagonal containment housing with a small reinforced window and amber/cyan status indicator.

## Rules
Use transparent elements sparingly; silhouette and color bands should still identify each variant if transparency renders poorly. Keep sample contents as separate replaceable objects. No text baked into texture; provide empty label plate for Roblox UI/decal. Use 1–3 shared materials and a common scale family.

## Performance
Aim for 1k–4k triangles per variant, no hidden internal shells that cannot be seen, clean pivots near geometric center or grip point (document which). Use robust handles and clamps thick enough to survive small-size viewing.

Premium authored game-asset quality, readable silhouettes, optimized clean topology, UV-ready PBR, no text/logo, no thin fragile pieces. Export each variant separately and as one preview collection.”
